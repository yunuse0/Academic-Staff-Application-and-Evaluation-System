# Academic-Staff-Application-and-Evaluation-System
This study presents a secure and role-based academic staff  recruitment system where candidates can upload their CVs  and apply for academic positions.

## About This Project:
Administrators can assign juries to job announcements, and jury members evaluate applicants by scoring and generating PDF reports. The system ensures identity validation using the Turkish Republic Identity Number SOAP service and separates access for applicants, juries, managers, and admins. Built using Next.js, TypeScript, Express.js, and Prisma ORM, the platform provides a modern and scalable approach to managing academic recruitment processes. Keywords — academic recruitment, role-based access, CV upload, SOAP service, jury scoring, PDF reporting
